# 生成式视频镜头语言

本参考吸收 [GrokFilm 镜头技术索引](https://grokfilm.app/#index) 中可迁移的镜头、构图和连续性分类，并转换为平台无关的提示词方法。不要照抄通用术语；展开成当前镜头的物理行为。

## 镜头选择顺序

1. `交代空间`：建立镜头、大全景、全景、主镜头。
2. `展示人物关系`：双人镜头、中景、过肩镜头、正反打。
3. `强调表情或信息`：中近景、近景、特写、插入镜头、焦点转移。
4. `跟随动作`：跟拍、横向跟踪、推进、拉远、摇摄、俯仰。
5. `制造主观感受`：手持、主观镜头、高低机位、倾斜构图、快速摇镜。
6. `维持连续性`：180 度轴线、视线匹配、动作匹配、30 度规则。

镜头必须服务动作和叙事，不因术语复杂而堆叠效果。

## 提示词语法

```text
主体与动作（中文）
+ 景别（中文）
+ 机位高度、俯仰和横滚角度（中文）
+ 摄影机相对人物的方位（中文）
+ 运动路径、方向、速度和稳定度（中文）
+ 焦距感、对焦对象、焦点变化和景深（中文）
+ 构图、人物方位、视线、头顶空间和运动留白（中文）
+ 光线、曝光、色彩和质感（中文）
+ 与前后镜头的连续性约束（中文）
+ 台词、环境音、音效、BGM 和字幕（字幕样式中文）
```

最终生成 Prompt 的可读正文统一使用简体中文。只有需要人物实际说出的英文口播台词，以及与台词逐字一致的英文字幕文本保留英文；不要把镜头术语、动作、摄影参数、负面约束或声音说明写成英文。

人物身份也必须使用中文的原创角色描述。不要在生成 Prompt 中写公众人物姓名、虚构角色名、系列/IP、品牌 Logo、专属服装标志或“像某人/某人风格”；如参考素材含有这些身份，只保留年龄、发型轮廓、脸部几何、服装色彩、动作能量和通用摄影特征，并明确“不使用可识别公众人物面孔、声音、Logo、商标或专属台词”。

只要有口播，字幕必须开启并写清：`subtitles: on`、字幕位于画面下方安全区、白色文字内填充、黑色描边。没有口播时才可以写关闭字幕。

不要只写“手持跟拍”。写成：

```text
眼平中景，摄影机位于人物右后方约一米，手持步行跟随人物向前移动，轻微自然上下起伏和小幅横向修正，不剧烈抖动，保持腰部以上入画，背景环境清晰可辨。
```

## 真人摄影与色彩默认基线

真人或写实人物默认采用奖项级、好莱坞成熟叙事摄影的通用方法，而不是抽象地写“奥斯卡风格”或某位导演姓名。提示词至少落到以下可执行维度：

- `调度`：人物在空间中的起始方位、行动路线、视线、前后景关系和 180 度轴线。
- `镜头`：景别、焦段感、机位高度/角度、摄影机相对主体的位置，以及一个主要运镜的路径、方向、速度和稳定度。
- `光线`：有动机的主光来源、辅光/负补光、轮廓光、阴影方向、曝光和高光保护。
- `色彩`：明确主色、辅色、背景色、冷暖关系和饱和度；默认丰富鲜艳、层次清楚，肤色自然且不出现色彩溢出。
- `质感`：景深、运动模糊、颗粒或干净度，以及真实材质和实景细节。

可从著名导演的成熟方法中抽取深焦空间调度、主观手持、精确正反打、长镜头节奏、广角近距离压迫感、长焦压缩、负空间或实景动机光等特征，再改写为上述参数。不得声称复刻某位在世导演，也不得用导演名替代镜头执行描述。

建议的默认色彩句式：

```text
丰富鲜艳的综合色彩，主色<...>、辅色<...>、背景色<...>；中高饱和但不过曝或溢色，肤色保持自然，阴影保留细节，主光与环境色温形成明确但连续的冷暖关系。
```

## 景别

| 术语 | 可执行描述 | 用途 |
| --- | --- | --- |
| 建立镜头 | 远距离展示地点、出入口、人物方位和路线 | 新场景开场 |
| 大全景/全景 | 人物全身与大面积环境同时入画 | 空间关系、场景参考图 |
| 主镜头 | 较宽景别连续覆盖主要表演 | 保底覆盖、多人调度 |
| 中景 | 人物腰部以上，保留环境上下文 | 街访、对话 |
| 中近景 | 人物胸部以上 | 口播、反应 |
| 近景/特写 | 面部或物体占据画面主体 | 表情、产品、手机屏幕 |
| 插入镜头 | 单独切近手、道具或 UI | 关键信息 |

## 机位与关系

| 术语 | 可执行描述 |
| --- | --- |
| 眼平机位 | 摄影机与人物眼睛等高，视角自然中性 |
| 高/低机位 | 摄影机明确高于或低于主体，并写清俯拍或仰拍 |
| 双人镜头 | 两人同时入画，写明左右站位、朝向和距离 |
| 过肩镜头 | 从一人肩后拍另一人，保留前景肩部 |
| 正反打 | 在轴线同侧交替拍摄对话者，保持屏幕方向 |
| 主观镜头 | 摄影机位于指定角色眼睛位置，表现其所见 |

## 摄影机运动

| 术语 | 可执行描述 |
| --- | --- |
| 静止/锁定 | 摄影机位置与角度不变，人物在画面内运动 |
| 手持 | 小幅自然呼吸和步行起伏，不等于剧烈乱晃 |
| 摇摄/俯仰 | 摄影机位置固定，仅水平或垂直旋转 |
| 跟踪 | 摄影机与主体同向移动，维持相对稳定构图 |
| 跟拍 | 摄影机从侧后方或后方追随主体穿过空间 |
| 推进/拉远 | 摄影机物理靠近或远离主体 |
| 光学变焦 | 摄影机不移动，只改变放大倍率 |
| 环绕/弧线 | 摄影机沿明确方向和角度范围绕主体移动 |
| 快速摇镜 | 高速转动并产生短暂运动模糊，只用于明确转场或节拍 |
| 焦点转移 | 机位基本不变，焦点在明确前后景主体间切换 |

## 连续性

### 180 度轴线

为对话或动作建立轴线。同一连续场景内保持摄影机在轴线同侧，使人物左右位置、朝向和视线方向稳定。

### 30 度变化

剪辑切换同一主体时，新机位角度至少变化约 30 度或明显改变景别，避免无意跳切。尾帧接力边界是连续镜头边界，不应用此规则。

### 视线匹配

写清人物看向画面左、右、上、下或具体物体。反打和插入镜头必须位于视线所指方向。

### 动作匹配

记录动作阶段，例如“右手刚抬到胸口”“钥匙仍在左手”“重心移向右脚”。后段从相同阶段继续，不重做完整动作。

### 尾帧接力

下一片段第一帧完全继承前段尾帧，再继续人物或摄影机运动。不要在接力边界同时要求立即切换反打、特写或新机位；需要改变镜头时，先承接尾帧，再在后续动作节点完成变化。

## 冲突检查

- 不同时写 `静止锁定` 与 `跟拍/推进/环绕`。
- 不同时写 `完全稳定` 与 `明显手持抖动`。
- 不同时写 `浅景深背景虚化` 与 `前中后景全部清晰`。
- 不把固定机位摇摄和摄影机横向平移混为一件事。
- 不同时写推进和拉远，除非明确先后。
- 不同时写光学变焦和物理推进，除非明确要求推拉变焦。
- 不同时要求继承尾帧和首帧直接切换新机位。

单镜头只选一个主要运镜。需要组合时最多加入一个次要动作并写明先后。

## 街访类默认组合

```text
眼平中景或双人镜头，两人腰部以上入画；摄影机位于两人侧前方或主持人侧后方；手持步行跟拍，只有轻微自然晃动；保持180度轴线和稳定左右站位；人物停下解释时轻微推近到中近景；手机或产品信息使用一次短暂插入特写；背景采用中等或较深景深，保留可识别环境。
```

喜剧反转优先依靠表演、停顿和反应完成，只在反转后加入轻微推近或反应近景。
