# Seedance 2.5 首尾帧角色动画 Prompt

本参考用于 5–6 秒为主的角色待机、呼吸和生气动画。它处理单个视频内部的首尾帧，不等同于多个视频片段之间的尾帧接力。

## 写法原则

Seedance 2.5 官方案例采用“素材职责 + 按时间展开的动作 + 收尾约束”的自然语言写法，并支持用时间戳控制节奏。对单角色、固定机位的短动画，默认只写一小段：

```text
首尾帧关系 + 2–3 段时间动作 + 固定项/禁项 + 声音
```

- 默认控制在约 `120–220` 个汉字；角色有关键道具或特殊姿势时可略长，但不写成长规格书。
- 使用平台实际显示的素材标签，如 `@图片1`；没有素材标签时写“首帧图/尾帧图”。不要虚构标签。
- 每段只放一个主要动作。少写抽象的“非常自然”，改写为能看见的呼吸部位、肌肉变化、重心和回位顺序。
- 关键固定项集中放在最后一句，不重复多轮正负约束。
- 官方能力说明与示例：[Seedance 2.5 官方发布](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)、[Seedance 2.5 官方模型页](https://seed.bytedance.com/en/seedance2_5)。

## 写 Prompt 前先看图

内部识别人物的初始表情、朝向、重心、手脚、服装、道具接触点、画面边距和背景。只把影响动作的锚点写进 Prompt，例如“拐杖始终着地”“篮子不换手”；不需要复述整套外貌。

先判定：

- `same_frame_loop`：同一张图作为首帧和尾帧；结束必须回到初始表情、姿势、重心、手脚和道具位置。
- `directed_transition`：首尾是不同图片；自然到达尾帧，不要求回到首帧。

只有一张图且用户要待机或生气循环时，按 `same_frame_loop` 写。Prompt 交付不代表平台已正确配置首尾帧，更不代表生成结果已通过一致性检查。

## 自然待机

不要照搬样片的呼吸幅度。更接近自然静息呼吸的表现是：

- 动作集中在下胸廓和上腹，幅度很小；锁骨、肩膀和头部基本稳定。
- 呼吸周期稳定，吸气平缓、呼气稍长，换气点柔和连续；不是全身上下升降或整体缩放。
- 支撑脚和骨盆不滑动。手指不乱动，道具接触点不变。
- 眨眼最多偶尔发生，速度短而柔和，与呼吸错开；不要强制每个短片固定眨眼次数。
- 衣领、衣摆、头发只做比身体更小、略有滞后的被动运动。

### 5 秒待机模板

```text
首帧与尾帧使用同一张图，生成5秒固定机位待机动画。0–2秒：角色保持原姿势，下胸廓与上腹极轻微吸气，肩颈、头部、骨盆和支撑脚稳定。2–5秒：平缓呼气，衣物和头发仅有微弱滞后，结束准确回到首帧的表情、视线、手脚和道具位置。呼吸节拍稳定、换气柔和，不做全身升降或缩放；人物、道具、构图、背景与光线不变，全程不出画，无镜头运动或转场。无对白、无BGM、无字幕。
```

时长不是 5 秒时，按总时长等比例调整。约 7–10 秒可写两个完整低幅呼吸周期；不要把所有时长都固定成一次呼吸。

## 自然生气

“生气”要写成动作链，不只写一个怒脸：

- 先让目光聚焦，笑意减弱；眉头向内下方收紧，眼睑略窄，下颌和嘴唇随后绷紧。
- 张力从面部传到肩颈和躯干，再进入一个主动作。两手空闲可选叉腰或单手握拳；手持拐杖、篮子、包等道具时，优先收紧握力并小幅前倾，不换手、不掉落。
- 峰值保留轻微呼吸和不完全对称的细小张力，不冻结、不高频抖动。
- 回位时先松手和下颌，再松肩颈、躯干和眉眼，最后恢复初始视线与重心；不要把前半段机械倒放。
- 动作可清楚但不过火。除非用户明确要求，不跺脚、跳起、尖叫、脸部通红或出现卡通怒气特效。

### 5 秒生气模板

```text
首尾帧使用同一张图，生成5秒固定机位生气动画。0–1.2秒：目光聚焦，笑意收住，眉头向内下方收紧，眼睑略窄，下颌绷紧。1.2–3.2秒：肩颈逐渐发力，<填写一个主动作>，呼吸略深，怒意清楚但不过火。3.2–5秒：先松手和下颌，再松肩颈、躯干与眉眼，回到首帧的表情、视线、重心和道具位置。人物、服装、道具、构图、背景与光线不变，全程不出画；无突然变脸、变形、运镜、转场、对白、BGM或字幕。
```

主动作必须落到角色身上，不能保留占位符。示例：

- 空手站立：`双手缓慢移到腰侧并收紧，肘部只小幅外展`。
- 手持拐杖和篮子：`握拐杖与篮柄的手指逐渐收紧，上身轻微前倾，拐杖始终着地`。
- 坐姿：`双手轻压膝部，上身小幅前倾`。
- 画面边距小：`只用眉眼、下颌和肩颈表达怒意，手脚保持原位`。

## 声音与交付

- 默认无对白、无BGM、无字幕。用户允许音效时，只追加一句：`仅保留与衣物或道具动作同步的轻微音效。`
- 用户同时要待机和生气时，输出两段独立完整 Prompt，不用“同上”或差异补丁。
- 首尾图已提供时，以图中角色、风格、构图和背景为准，不套用欧美化、增艳或新摄影风格。
- 不把长篇角色分析、模型参数、任务 ID、文件路径或验收说明塞进生成 Prompt。

## 成片验收

生成后解码首个和最后一个有效画面。严格“首尾一致”必须逐像素或用等价的确定性方法检查；提示词写了“一致”、平台使用同一张图或肉眼相似都不等于通过。另查呼吸是否局部低幅、表情与身体是否按顺序变化、人物是否出画，以及脚底、手指、道具、背景和机位是否漂移。
