# 复刻质量门槛

## Gate 1：输入真实

- 参考素材存在且可访问。
- 文件路径、URL、附件或素材节点有可验证证据。
- 读取不到的媒体参数保持未知。

## Gate 2：执行器可行

- 实际生成前重新核验执行器能力。
- 连续片段必须支持场景参考图和指定首帧。
- 片段上限不超过执行器上限。
- 不支持原生声音时已有明确后期方案；有对白时还要确认逐句文本、英语/地区变体、声音表演和唇形同步路径。
- 没有能力证据时不得报告可执行。

## Gate 3：原片账本完整

- 每个镜头有 ID、时间范围和剧情功能。
- 每句台词有 ID、说话人、所属镜头和原始顺序。
- 钩子、冲突、反转、证明点和 CTA 有归属。
- 不确定内容标记为 `待确认`。
- 对新写或改写的说话内容，另有完整 `dialogue_delivery_sheet`；不能以抽象台词意图代替文本。

## Gate 4：改写可追溯

- 每个原台词 ID 恰好映射一次，或有明确确认的删除记录。
- 未指定修改的内容从原片账本继承。
- 人物、场景、产品、品牌、道具和 CTA 替换关系无歧义。
- 仅要求分段时没有压缩剧情或删减对白。

## Gate 5：片段正确

- 每个镜头只进入一个片段。
- 片段内空间、时间、人物、动作和情绪连续。
- 声明时长与镜头之和误差不超过 `0.25s`。
- 片段不超过流程与执行器的较低上限。
- 生成顺序唯一且连续。

## Gate 5A：核心脚本锁定与变体隔离

- 原脚本以 `core_script` 保存，`frozen` 为 `true`，核心节拍和台词 ID 唯一且顺序稳定。
- `core_script.dialogue_texts` 与原台词账本一致；冻结模式下每个变体的对白覆盖为空，台词文本和语义不变。
- `variant_policy` 明确允许轴、禁止轴、变体数量和每个变体的变化上限。
- 每个变体列出 `changed_axes`、`delta` 和完整的 `preserved_core_ids`；变化轴必须获准，禁止轴不得出现。
- 每个核心节拍、台词、产品主张和 CTA 在每个变体中恰好保留一次；不能通过删节或新增节拍伪造变体。
- 变体从同一冻结基线独立生成，不得继承其他变体的修改、参考图或尾帧。
- 人物/服装/场景发生变化时，为该变体建立独立场景参考图；同一变体内部仍复用自己的参考图和尾帧链。
- 每个变体都有完整的可复制 Prompt；Prompt 不得依赖“同上”、其他变体或用户自行拼接。
- 长脚本的每个变体都具备自己的 A/B/C 分段 Prompt 和尾帧依赖说明。

## Gate 6：场景参考图已锁定

- 每个连续场景都有唯一参考图 ID 和实际资产。
- 图片覆盖人物、完整服装、道具、空间结构、方位和光线。
- 同场景片段引用同一基准。
- Prompt、路径占位符或待生成状态不算资产就绪。

## Gate 7：尾帧交接真实

- 前段已验收通过。
- 尾帧来自通过版视频末尾附近，记录来源、时间点、路径和哈希。
- 尾帧不是黑帧、转场帧或严重模糊帧。
- 后段首帧与前段尾帧是同一资产。
- 后段同时引用当前场景参考图。
- 前段尾帧未就绪时后段不得启动。

## Gate 8：接缝连续

- 人物身份、服装、姿态、视线、表情和手部状态连续。
- 道具数量、样式、持有手和位置一致。
- 人物方位、朝向、景别、机位、光线和运动方向一致。
- 没有瞬移、跳轴、动作重置或无意构图突变。
- `hard_cut` 有真实场景/时间变化、原因和新参考图。

## Gate 9：声音一致

- 逐镜与片段 Prompt 的 BGM、环境音、对白和字幕要求一致。
- `无 BGM` 与 `加入 BGM` 不能同时出现。
- 声音策略变化后重新确认。
- 台词账本、逐镜 Prompt、分段 Prompt 和交付表中的台词文本逐字一致；语言/地区变体、表演要求、唇形同步和字幕开关都有记录。
- 有对白的镜头必须有完整可朗读台词；无对白的镜头明确写 `无对白`，不得留空造成歧义。
- 用户最新明确要求显示字幕时，`subtitles` 必须为 `on`，逐句字幕文本与台词一致，并记录下方安全区位置和字幕样式；不得被旧 Prompt 的“不要字幕”约束覆盖。
- 用户未明确字幕要求但输入约束冲突时，必须列为待确认，不得静默改成无字幕。

## Gate 9A：默认创作基线

- 未被用户覆盖的新生成内容使用欧美地域语境、英文对白和丰富鲜艳但不溢色的综合色彩。
- 真人或写实人物的导演参考已经转译为焦段、机位、调度、运镜、布光、曝光、色彩和质感参数；导演姓名或“电影感”不能单独作为证据。
- 默认值不覆盖可验证的原片事实、用户已确认的 `core_script` 或明确的地域/语言/色彩要求。

## Gate 10：确认有效

- “再看看”“台词要改”“方案不错”不等于生成授权。
- 只有明确的“确认生成”或清晰等价表达才进入外部生成。
- 关键字段修改后旧确认失效。

## Gate 11：状态有证据

- Prompt 已写不等于资产已生成。
- 文件选择器打开不等于附件上传成功。
- 任务提交不等于结果完成。
- 路径预填不等于尾帧已提取。
- 结果必须可查看才进入验收。
